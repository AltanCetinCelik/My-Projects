# AI, Edge, and Automation Portfolio

A public portfolio of engineering work focused on AI systems, industrial monitoring, edge computing, and automation.

This repository brings together reusable demos, prototype systems, and portfolio-ready projects that demonstrate practical engineering in Python, edge tooling, AI agent workflows, and backend/data pipeline design.

---

## Featured projects

### `industrial-iot-edge-demo`
Industrial edge + SCADA style demo built around synthetic machine telemetry, a lightweight edge parser, and a live dashboard.

- Synthetic machine data generation
- Edge-side data flow and parsing patterns
- FastAPI backend and real-time dashboard
- Industrial monitoring concepts in a sanitized, portfolio-safe format

**Stack:** Python · FastAPI · Pydantic · UART/CAN concepts · HTML/CSS/JS · pytest

```bash
pip install -r industrial-iot-edge-demo/requirements.txt
uvicorn backend.main:app --reload
python simulator/machine_simulator.py
```

### `luna-companion`
An interactive web companion prototype built with React and TypeScript for a playful, memory-driven user experience.

### `seed-agent-os`
An experimental agent orchestration repository focused on local AI workflows, guardrails, memory, and automation prototypes.

### `python-seed-lab`
A training-focused Python repository for control-room patterns, memory experimentation, and local AI workflows.

## What this repo is for

This is intended as a clean, public-facing project hub for demonstrating engineering depth, product thinking, and practical systems work without exposing proprietary or personal data.

The goal is to present work in a way that is easy to understand, credible to hiring teams, and useful for technical review.
